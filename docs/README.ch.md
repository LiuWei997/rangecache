# rangecache 要解決什麼問題

[English version](../README.md)

一般 cache 會把每個查詢區間視為不同的 cache key。例如已經查過 `[01:00, 14:00)`，下一次查詢 `[00:00, 15:00)` 時，即使大多數資料已經讀過，仍可能再次查詢整段範圍。

rangecache 適合有順序、以新增為主的資料，例如 event log、交易紀錄與 audit record。

它會為每個 logical query key 記住兩件事：

- 已快取的資料列
- 已經向資料來源確認過的區間

當新的查詢和既有區間重疊時，rangecache 只需要查尚未確認的部分，再和原有資料合併。即使某個區間沒有資料，也會記住它已經查過，避免之後重複查詢空區間。

```text
已確認：  [01:00, 14:00)
新查詢：  [00:00, 15:00)
只查詢：  [00:00, 01:00), [14:00, 15:00)
```
